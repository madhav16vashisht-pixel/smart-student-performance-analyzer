📌 Project: Smart Student Performance Analyzer

Built using Python 3.11 and its standard library, this command-line application helps organize student marks and generate performance insights.

✨ Features:
• Student record management
• Marks validation and grade calculation
• Percentage calculation and student ranking
• Search by student name or ID
• Class average, topper, and subject-wise averages
• Persistent storage using JSON file handling
• Text report generation

🛠️ Python concepts practised:
Variables, loops, conditionals, functions, lists, dictionaries, sorting, exception handling, and file handling.
